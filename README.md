## 🎥 Entrega

Cada equipe deverá entregar um **vídeo de apresentação de no máximo 5 minutos** demonstrando o funcionamento completo do projeto desenvolvido.

## ✅ Requisitos do sistema

### O sistema entregue deverá conter

- [ ] Código em Python ou notebook organizado
- [ ] Uso de banco de dados ou arquivo estruturado compatível com a proposta
- [ ] Operações CRUD ou simulação clara dessas operações
- [ ] Tratamento de erros em pelo menos uma parte relevante do código
- [ ] Pelo menos uma regra booleana aplicada ao funcionamento do sistema
- [ ] Representação, explicação ou simulação de circuito lógico, sensor, atuador, Arduino ou Tinkercad (quando escolhido pela equipe)
- [ ] Uso justificado de estruturas de dados estudadas na fase
- [ ] Simulação computacional relacionada à sustentabilidade ou à operação da colônia
- [ ] Aplicação de conceito matemático coerente com a simulação ou análise
- [ ] Modelo linear simples para previsão, estimativa ou apoio à decisão
- [ ] Proposta de integração de IA por agentes, ferramentas, fluxos ou guardrails
- [ ] Explicação sobre arquitetura computacional, processamento, memória ou aceleração
- [ ] Análise socioambiental e de cidadania digital conectada ao protótipo

### O sistema também deverá apresentar

- [ ] Menu simples de navegação no terminal, interface textual, notebook organizado ou fluxo demonstrável
- [ ] Dados organizados de forma clara
- [ ] Mensagens de entrada e saída compreensíveis
- [ ] Comentários no código explicando as principais etapas
- [ ] Exemplos de execução das funcionalidades implementadas

## ⚙️ Funcionalidades

As funcionalidades implementadas deverão permitir:

- [ ] Cadastrar ou carregar dados da colônia
- [ ] Consultar registros operacionais, sustentáveis ou de sensores
- [ ] Alterar ou excluir registros (quando a equipe utilizar CRUD completo)
- [ ] Executar uma regra lógica de decisão
- [ ] Exibir ou explicar o circuito lógico relacionado
- [ ] Executar ou apresentar uma simulação computacional
- [ ] Executar ou simular um modelo linear simples
- [ ] Utilizar uma estrutura de dados para organizar, buscar, priorizar ou representar informações
- [ ] Exibir uma análise final dos resultados e das limitações do sistema

### 💡 Exemplo de funcionalidade esperada

Ao selecionar a opção **"Analisar sustentabilidade da colônia"**, o sistema poderá:

1. Consultar registros de módulos no banco de dados;
2. Identificar leituras de consumo;
3. Aplicar uma regra booleana para classificar o risco;
4. Utilizar uma estrutura de dados para organizar os alertas;
5. Executar uma simulação simples de consumo;
6. Estimar uma variável com regressão linear;
7. Exibir uma recomendação técnica validada por critérios de sustentabilidade e responsabilidade social.
